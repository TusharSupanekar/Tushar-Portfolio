# Tushar Supanekar | Portfolio

Personal portfolio for Tushar Ashok Supanekar, a full-stack software engineer focused on scalable web applications, real-time systems, and AI-powered products.

## Highlights

- Featured electronic trading exchange and order-matching engine
- React, TypeScript, Python, Java, FastAPI, PostgreSQL, Docker, and AI/ML experience
- Professional experience, education, certifications, and selected projects
- Responsive dark interface built with React and Material UI
- Contact form that opens a prefilled email draft
- Downloadable resume and profile photo assets

## Tech Stack

- React 19 with Vite
- Material UI and Material UI Icons
- Emotion styling
- JavaScript (ES6+)
- CSS with responsive layout and motion

## Run Locally

```bash
git clone https://github.com/TusharSupanekar/Tushar-Portfolio.git
cd Tushar-Portfolio
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Production Build

```bash
npm run build
npm run preview
```
